# ⏳ Жизнь в неделях

**Вся жизнь на одном экране: около 4000 клеток-недель.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/life-weeks/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Прожитое, текущая неделя и недели впереди
- Важные события на карте жизни
- Статистика: дни, недели, удары сердца
- Подсказка с датой при наведении на клетку

## Стек

JavaScript, CSS Grid, даты. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/life-weeks.git
cd life-weeks
python3 -m http.server 8000
```
